# Documentation wiki

This folder is the project’s developer wiki. It is intentionally split into smaller, focused documents so the project history, architecture, and operational guidance stay easier to maintain.

## Documents

- [Project overview](project-overview.md) — what the project does and why it exists
- [Architecture](architecture.md) — system components and execution flow
- [Developer setup](developer-setup.md) — prerequisites, environment variables, and local commands
- [Operations](operations.md) — runtime behavior, logging, and failure handling

## Scope

This wiki complements the root `README.md`. The root README is the short developer-facing entry point; the documents in this folder provide deeper operational context.
